# ✅ Checkmate 📝
Checkmate is a minimalist, browser-based to-do list app built entirely with front-end technologies. It’s designed to demonstrate clean, responsive UI design and practical use of the DOM and local storage—no frameworks, no dependencies, just HTML, CSS, and JavaScript.

## 🧱 Project Overview
Checkmate provides users with a simple, elegant way to manage daily tasks directly in the browser. It automatically saves progress locally, so your tasks persist even after refreshing or closing the page.

## 💡 Key Features
* ✍️ Add and delete tasks easily using the input field and buttons
* ✅ Mark tasks as complete with a simple click (toggle checked state)
* 💾 Auto-save functionality via browser local storage — no server required
* 📱 Responsive design that adapts beautifully to mobile and desktop screens
* 🎨 Custom theming using CSS variables for easy style adjustments
* 🧰 Technologies Used

## ✅ HTML5
* Structured a clean, semantic single-page layout
* Included accessible input and button elements
* Added footer links for creator attribution and hosting details

## ✅ CSS3
* Built a modern, visually appealing interface using Flexbox
* Used custom CSS variables for color themes (--highlight-color, --container-color)
* Designed a responsive layout that scales on small screens
* Styled interactive elements like task completion states (checked/unchecked)

## ✅ JavaScript (Vanilla JS)
* Implemented DOM manipulation to dynamically create, update, and delete tasks
* Added click event listeners for marking tasks complete or removing them
* Stored and retrieved tasks using localStorage for persistent state
* Built entirely without external libraries or frameworks to showcase core JS logic

## ⚙️ How It Works
* Enter a task into the input box.
* Click Add or press Enter to add it to the list.
* Click on a task to mark it as done (adds a strike-through).
* Click the ❌ icon next to a task to remove it.
* All changes are automatically saved in your browser.
